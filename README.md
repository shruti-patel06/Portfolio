# Portfolio

My personal portfolio: projects, hackathon work, skills and a way to get in touch.

Live site: https://shruti-patel06.github.io/Portfolio/

## Structure

```
index.html              page markup
assets/
  css/styles.css        styles, light and dark themes
  js/main.js            interactions: ID badge, project filters and details, contact form
  js/projects.js        project details shown in the case-study dialog
  images/               portrait and favicon
```

It's a static site with no build step, hosted on GitHub Pages. The contact form sends messages through Web3Forms.
